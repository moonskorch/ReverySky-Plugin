# What's New in 1.5.0

## Landmarks

Landmarks add a context cloud around each note directly in the graph. Notes are planets, and Landmarks are points of interest on them: names, places, events, concepts, keywords, and other details that make each note distinct.

By default, ReverySky uses the note's `landmarks` property. You can choose any other text property as the Landmark source and switch between properties while the graph is open, bringing different layers of context into view without changing the layout.

### Adding a landmark

To quickly add one from a note:

1. Select a word or phrase.
2. Right-click the selection.
3. Choose **Add to landmarks** or **Add to `<property name>`** when using another Landmark source.

If the graph is already open, the new landmark appears immediately.

Use the round view button to switch views without changing the layout: the same spatial structure can be viewed through connections or through Landmarks.
