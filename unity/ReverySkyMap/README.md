# ReverySky Map Unity Project

This directory contains the Unity WebGL part of the ReverySky Obsidian plugin.

The project can be opened in the Unity Editor for development and Play Mode testing. Its WebGL build is designed to run as part of the parent Obsidian plugin and use data provided by the plugin integration.

Some third-party visual source files are intentionally excluded from Git and must be added manually after cloning the repository.
